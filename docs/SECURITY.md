# Publication and Security Rules

This repository contains **personal or simulated infrastructure only**.

Do not publish:
- Employer or client names, floor plans, rack layouts, schematics or screenshots without explicit authorization.
- Passwords, API tokens, private keys, session cookies, SNMP community strings or database dumps.
- Public IP addresses, internal DNS names, serial numbers, user details or access information that could expose real systems.
- Live production configuration files or proprietary documentation.

Use synthetic names and example IP ranges (192.0.2.0/24, 198.51.100.0/24, 203.0.113.0/24) in published examples. Keep real lab credentials in local environment files excluded by .gitignore. Review exported dashboards, screenshots and metadata before committing.

Never connect SCADA exercises to real industrial equipment or production networks. Simulate control signals in an isolated lab.
