# 24-Week Practical Roadmap

**Study target:** approximately 5 hours/week. Dates are flexible; advance based on verified competency.

| Week | Focus | Practical deliverable |
|---|---|---|
| 1 | Ubuntu VM audit | Resource and service inventory, sanitized |
| 2 | Linux essentials | SSH, users, permissions exercises |
| 3 | Linux troubleshooting | Diagnose and recover a test service |
| 4 | Zabbix fundamentals | CPU, RAM, disk and network monitoring |
| 5 | Zabbix templates | Reusable template and macros |
| 6 | Zabbix agents | Linux and Windows hosts |
| 7 | SNMP | Simulated network device monitoring |
| 8 | Alerting and discovery | Tested triggers and alert actions |
| 9 | NetBox installation | Accessible NetBox lab |
| 10 | DCIM inventory | Site, location, rack and devices |
| 11 | IPAM and cabling | VLANs, prefixes, interfaces and traces |
| 12 | NetBox API | Read-only inventory export |
| 13 | Grafana installation | Zabbix data source |
| 14 | Dashboard design | Core monitoring panels |
| 15 | Advanced visualization | Variables, thresholds and annotations |
| 16 | Operations dashboard | Documented dashboard export |
| 17 | SCADA fundamentals | PLC, HMI and signal model |
| 18 | Modbus TCP | Isolated register simulation |
| 19 | Simulated CRAH | Temperature and fan-state logic |
| 20 | Monitoring integration | Tested simulated alarm |
| 21 | Inventory reconciliation | NetBox and Zabbix mapping |
| 22 | Integrated dashboard | Cooling and host metrics |
| 23 | Fault investigation | Reproducible incident report |
| 24 | Final assessment | End-to-end demonstration |

## Completion criteria
A week is complete only when the exercise is reproduced, its result is verified, and evidence is committed. Record unresolved problems explicitly. Never claim professional certification based on lab completion alone.
